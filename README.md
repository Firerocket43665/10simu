# 🪟 Windows 10 Simulator (Web)
一个用纯 HTML + CSS + JavaScript 写出来的 **Windows 10 网页模拟器**，单文件即可运行，无需任何框架或后端。
> ⚠️ 这不是虚拟机，不是操作系统——它是一个**高保真界面演示**，所有交互都在浏览器标签页内完成。
## ✨ 已实现功能
### 🖥 桌面与窗口系统
- 桌面图标、任务栏、开始菜单（含磁贴）
- 窗口拖拽 / 缩放 / 最小化 / 最大化 / 关闭
- 右键菜单（桌面、任务栏、文件列表）
- 操作中心、日历、电源菜单
- 锁屏界面（模拟密码登录）
### 📁 文件与资源管理
- 此电脑（C: / D: 驱动器）
- 回收站（清空 / 还原）
- 虚拟文件系统，支持双击打开文件
### 📦 内置应用
| 应用 | 说明 |
|------|------|
| **记事本** | 真实可编辑，字符计数 |
| **Edge 浏览器** | ✅ 真实网页加载（多标签页、地址栏、前进后退） |
| **酷狗音乐** | 播放列表、进度条、封面旋转 |
| **计算器** | 标准计算模式 |
| **命令提示符** | 支持 `help` `dir` `ver` `echo` `ipconfig` `start` `cls` 等命令 |
| **任务管理器** | 实时 CPU / 内存 / GPU / 磁盘 / 网络图表 |
| **注册表编辑器** | ✅ 完整读写，数据持久化到 localStorage |
| **控制面板** | 系统信息、个性化、程序卸载、关于 |
| **设置** | 个性化（壁纸上传）、网络、账户、更新、隐私等 |
| **画图** | 自由绘制 |
| **照片** | 图片浏览 |
| **天气 / 资讯 / 时钟** | 信息展示 |
| **Office 2002（试用版）** | Word / Excel / PPT 文件查看 |
| **Microsoft Store** | 界面展示 |
### 🔔 托盘交互
- **网络面板** — 连接状态、可用网络切换、飞行模式
- **声音面板** — 主音量 + 双扬声器独立控制、音量合成器
- **电池面板** — 真实电量读取（Battery Status API），无电池时显示"正在使用电源适配器
